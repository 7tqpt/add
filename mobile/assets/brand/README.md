# أصول العلامة

ملفّان:

| الملفّ | ما هو |
|---|---|
| `app_icon_ai.png` | **الأصلُ كما وُلد** من مولّد الصور — أزرقُ وفيه شارةُ المولّد. لا يُمسّ. |
| `app_icon.png` | **النسخةُ النبيذيّة** التي تُبنى منها الأيقونات. مولَّدةٌ من الأوّل. |

## الخطوتان

```bash
cd mobile
python3 tool/recolour_icon.py                        # الأصل ← نبيذيّ وذهب
python3 tool/make_icons.py assets/brand/app_icon.png # المقاسات كلُّها
```

الأولى تُخرج `app_icon.png`، والثانية تكتب أيقوناتِ أندرويد **وآيفون**.

**ولمَ خطوتان لا صورةٌ تُلصق:** التحويلُ يُعاد إن تبدّلت الهويّة، ويُقرأ
فيُعرف ما وقع. وصورةٌ تُلصق لا يعرف أحدٌ بعد شهرٍ كيف صُنعت.

## ما يتكفّل به `recolour_icon.py`

- **الأزرقُ يصير نبيذيّاً** بسلّمٍ يحفظ الضوءَ والظلّ — لا لوناً مسطّحاً
  يُبدَّل بلون. ومرابطُ السلّم **تُقاس من الصورة في كلّ تشغيل**، فلا رقمَ
  يعتّق إن بُدّل العمل.
- **الفضّيُّ يصير ذهباً** — «فرحتي» والقلب. والفضّيُّ على النبيذيّ يبرد
  ويشبه الرماد.
- **الكتلُ الدخيلةُ تُطمس** — شارةُ «Made with AI» ونحوُها. والقاعدةُ أنّ
  العملَ كتلةٌ واحدةٌ متّصلة، وما انفصل عنها زائد.

## ما يتكفّل به `make_icons.py`

- المقاساتُ الخمسة لأندرويد، وطبقتا الأيقونة المتكيّفة، وأرضيّتُها.
- **ومقاساتُ آيفون وآيباد** — تُقرأ من `Contents.json` نفسِه لا من قائمةٍ
  منسوخة، وتُحفظ **بلا قناة ألفا** وبلا زوايا مستديرة: App Store يرفض
  الاثنين، والنظامُ يقصّها بقناعه هو.
- زوايا العمل السوداء تُملأ بلون أرضيّته.

## للتجربة بلا مساسٍ بالمشروع

```bash
python3 tool/recolour_icon.py --out /tmp/x.png
python3 tool/make_icons.py /tmp/x.png --out /tmp/preview
```
