# أصول العلامة

ضع هنا **`app_icon.png`** — مربّعٌ ‎1024×1024‎ فأكثر — ثم شغّل من مجلّد
`mobile/`:

```bash
python3 tool/make_icons.py assets/brand/app_icon.png
```

يولّد المقاسات الخمسة وطبقتَي الأيقونة المتكيّفة وأرضيّتها.

## ما يتكفّل به السكربت — فلا تُعالج الصورة قبله

- **الهامش الأسود** حول العمل يُقصّ، ومعه شارةُ «Made with AI» إن كانت فيه
- **زوايا العمل** السوداء تُذاب في لون أرضيّته، فلا تظهر لطخاتٌ تحت القناع
  الدائري
- **لون الأرضية** يُؤخذ من حافّة العمل نفسه، فما يظهر خلف قناع الجهاز امتدادٌ
  للأيقونة لا لونٌ غريبٌ عنها

## للتجربة بلا مساسٍ بالمشروع

```bash
python3 tool/make_icons.py <صورة> --out /tmp/preview
```
