# لوحة التحكم برنامجاً على سطح المكتب

الواجهة هنا هي نفسها التي تعمل على `sdd.company` — لا نسخة ثانية تتخلّف عن
الأولى. تُبنى مرّةً بـ Vite، ثم تُحزم داخل نافذةٍ أصلية.

## لماذا Tauri لا Electron

| | Tauri | Electron |
|---|---|---|
| حجم المُثبِّت | ‏~١٠ ميغابايت | ‏~١٥٠ ميغابايت |
| محرّك العرض | WebView2 المُثبَّت في ويندوز أصلاً | نسخة Chromium كاملة في كل برنامج |
| الذاكرة عند التشغيل | ‏~٨٠ ميغابايت | ‏~٣٠٠ ميغابايت |

والفرق ليس تفاخراً بالأرقام: البرنامج يُنزَّل على أجهزة موظفين، وقد يُنقل
على وصلةٍ بطيئة أو بذاكرةٍ محمولة.

## ما يزيده البرنامج على صفحة الويب

ثلاثةٌ لا تستطيعها صفحةٌ في متصفّح، وكلٌّ منها مكتوبٌ لسببٍ لا للزينة:

1. **حفظ التقارير بحوارٍ حقيقيّ.** التصدير في المتصفّح `<a download>` —
   وهي أداةُ متصفّح: داخل نافذة برنامجٍ إمّا أن تُنزل الملف في مجلّدٍ لم
   يختره أحد، وإمّا ألّا تفعل شيئاً بصمت. فالبرنامج يسأل أين يُحفظ، كما
   يفعل كل برنامجٍ آخر على الجهاز. (`src/lib/csv.ts` و`src/lib/desktop.ts`)

2. **الروابط الخارجية تُفتح في المتصفّح** لا داخل إطار البرنامج — فنافذةٌ
   بلا شريط عنوانٍ ولا زرِّ رجوعٍ مصيدةٌ لا متصفّح.

3. **النافذة تتذكّر حجمها وموضعها** بين الجلسات.

وتبدأ النافذة مخفيّةً وتُظهر نفسها بعد أوّل إطارٍ مرسوم (`revealWindow` في
`src/main.tsx`)، وإلا رأى المستخدم إطاراً أبيض فارغاً في كل تشغيل.

## البناء

المُثبِّتات تُبنى في GitHub Actions — لا حاجة إلى جهاز ويندوز ولا ماك:

- **Actions ← «بناء برنامج سطح المكتب» ← Run workflow** ← يبني ويندوز
- أو ادفع وسم إصدار (`git tag v1.0.0 && git push --tags`) ← يبني الأنظمة
  الثلاثة وينشرها في Releases

للبناء محلياً تحتاج [Rust](https://rustup.rs) ثم:

```bash
npm run desktop:dev     # نافذة تُحدَّث مع كل تعديل
npm run desktop:build   # مُثبِّتٌ في src-tauri/target/release/bundle
```

وعلى لينكس وحده تلزم مكتبات نظام (ويندوز وماك يكفيهما ما فيهما):

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev patchelf
```

## المفاتيح

`VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` تُخبز في البناء. والمفتاح
العام مصمَّمٌ لهذا — يعمل في متصفّحٍ أو برنامجٍ مُوزَّع، والحماية في سياسات
RLS لا في إخفائه.

**ولا يدخل هنا `service_role` ولا كلمة مرور القاعدة أبداً.** كلاهما يتخطّى
RLS كلّياً، والبرنامج المُوزَّع يُفكّ ويُستخرج ما فيه في دقائق.

## التوقيع

المُثبِّت غير موقَّع، فيقول ويندوز «Windows protected your PC» أوّل مرّة —
ويُتجاوز بـ More info ← Run anyway. وإسكاتُ الرسالة نهائياً يحتاج شهادة
Code Signing سنوية تُشترى باسم الشركة؛ وهي قرار عملٍ لا خطوةُ برمجة.
